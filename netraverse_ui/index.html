A world-model AI that learns the evolving state of a network from traffic telemetry and forecasts attacker progression before compromise completes — not another single-flow classifier.

THE PROBLEM

Intrusion detection today answers "is this flow malicious?" — one packet, one verdict, after the fact. Defenders of Critical Information Infrastructure need the next question answered: "where is this network heading in the next five minutes, and what should I do now?" NetraVerse models the network as a dynamical system, learns its state-transition dynamics, and rolls the state forward to forecast the probability and MITRE ATT&CK stage of an attack campaign — with enough lead time to act.

CORE ALGORITHMS
RSSM-lite world model

Encoder (MLP) → GRU-based latent transition P(zt+1|zt) → decoder (MLP). A genuine latent-dynamics model, not an LSTM classifier in disguise: risk shown to the analyst is always decoded from a latent state, and forecasts come from prior-only imagination.

K-step forward rollout

From any current snapshot the model imagines forward window by window to a 300 s horizon, producing an infiltration-probability timeline and a predicted ATT&CK stage per step.

GNN host-graph modeling

Nodes = hosts, edges = flows. Graph message passing captures lateral movement and multi-host spread that per-flow anomaly scores miss. Attacker/victim roles are derived per window, never hardcoded.

Counterfactual what-if engine

An operator action is applied as an intervention on the latent state and the rollout is re-run — the "no action vs with action" branches are compared so the projected risk change is visible before committing.

Captum / SHAP attribution

Every surfaced forecast carries a feature attribution — fan-out, failed-auth rate, beacon regularity, byte asymmetry — so the analyst sees why, not just a number.

Deterministic decision engine + LLM narration

Recommended actions come from a deterministic rule engine (auditable). A local LLM via Ollama only narrates the reasoning in analyst language — it never makes the decision.

THREE INPUT MODES · ONE MODEL
CSV UPLOAD

Flow-record replay

Upload CIC/CTU-style NetFlow/IPFIX records. NetraVerse replays them window by window, building the forecast curve causally and pausing for a decision the moment a campaign is predicted.

PCAP UPLOAD

Packet-level replay

Upload a raw capture. Packets are reassembled into flows, packet-level features are fused with flow features through the same schema, then the same rollout and decision loop runs.

LIVE MONITOR

Sensor mode

A live sensor streams 60 s windows off an interface. The same world model forecasts campaigns in real time and surfaces the Accept/Modify/Reject loop as they emerge.
