# Benchmarks

Generated by `python -m src.training.report` from `reports/*.json`. Target: *does this host take part in attack activity at any point in the next 300 s* (5 x 60 s windows), evaluated per host and window on the held-out **test** blocks. The threshold is chosen on the validation blocks only. "Early-warning recall" covers only sequences whose 10-minute history is fully benign while an attack starts inside the horizon, i.e. true *prediction before onset*.
